## Phase 2: Consolidate Config into pyproject.toml

### 2.1 Move .coveragerc → pyproject.toml

Add to `pyproject.toml`:

```toml
[tool.coverage.run]
source = ["src"]
omit = ["tests/*", "demos/*", "__init__.py", "*/__init__.py"]
branch = true

[tool.coverage.report]
exclude_lines = [
    "pragma: no cover",
    "if __name__ == '__main__':",
    "raise NotImplementedError",
]
show_missing = true

[tool.coverage.html]
directory = "coverage_html"
```

Then delete `.coveragerc`.

### 2.2 Move pyrightconfig.json → pyproject.toml

Add to `pyproject.toml`:

```toml
[tool.pyright]
include = ["src"]
exclude = ["**/__pycache__", "build", "dist", ".venv"]
pythonVersion = "3.10"
typeCheckingMode = "basic"
```

Then delete `pyrightconfig.json`.

### Commands

```bash
# After updating pyproject.toml
rm .coveragerc pyrightconfig.json
git rm .coveragerc pyrightconfig.json
```

## Phase 9: Update Makefile

Ensure `Makefile` has targets to replace deleted scripts:

```makefile
.PHONY: test lint typecheck coverage clean

test:
	python -m pytest tests/ -v

coverage:
	python -m pytest tests/ --cov=src --cov-report=html --cov-report=xml

lint:
	ruff check src/ tests/

typecheck:
	pyright src/

clean:
	rm -rf coverage_html/ .coverage coverage.xml __pycache__ .pytest_cache
```

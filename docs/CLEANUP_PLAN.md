# Repository Root Cleanup Plan

## Executive Summary

The repository root currently has **58 items** (files + directories), which is excessive. A well-organized Python repository typically has **20-30 items** at root. This plan details a phased cleanup to reduce clutter, improve organization, and establish maintainable conventions.

**Current State:**
- 58 root-level items (should be ~25-30)
- 11 standalone Python scripts scattered at root
- 3 redundant output directories
- 2 duplicate demo directories
- ~1MB of generated/artifact files tracked in git
- 34MB of PDF research papers tracked in git

**Target State:**
- ~28 root-level items
- Scripts organized in `scripts/` directory
- Single `outputs/` directory
- Single `demo/` directory with archived examples
- Generated files excluded from git

## Phase 3: Handle Research Papers (lit/ directory)

**Risk Level:** Medium - 34MB of PDFs adds significant repo bloat

### 3.1 Analysis

The `lit/` directory contains 8 PDF research papers (34MB total):
- Attention Is All You Need (Transformer paper)
- GPT-3 paper
- Constitutional AI papers
- Deep Learning textbook (17MB alone)

### 3.2 Recommendation: Remove from Git, Document References

**Justification:**
1. PDFs are binary files that don't benefit from version control
2. 34MB is significant repo bloat (larger than all source code combined)
3. `.gitignore` already has `*.pdf` but these were added before that rule
4. These are published papers available from original sources

### 3.3 Alternative: Keep in docs/research/

If the team wants to retain the papers:
```bash
mkdir -p docs/research/papers
mv lit/* docs/research/papers/
rmdir lit
```

### 3.4 Recommended Approach

Create a `docs/research/REFERENCES.md` with links to papers, then remove PDFs:

```bash
# Remove from tracking
git rm -r lit/

# Create references document instead
# (See Phase 3 implementation for content)
```

## Rollback Strategy

Before starting, create a backup branch:

```bash
git checkout -b backup/pre-cleanup-$(date +%Y%m%d)
git push origin backup/pre-cleanup-$(date +%Y%m%d)
```

If any phase causes issues, revert that phase's commit:

```bash
git revert <commit-hash>
```
